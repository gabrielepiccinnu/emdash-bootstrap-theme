# @emdash-cms/template-bootstrap

## 0.1.0

### Features

- Full blog starter with Bootstrap 5.3 (installed via npm, not CDN)
- Native Bootstrap dark mode toggle (Light / Dark / Auto) with cookie persistence and anti-FOUC inline script
- Sticky navbar with dropdown sub-menu support (one level deep, driven by EmDash menu system)
- Live search integrated in navbar with `Ctrl+K` / `⌘K` shortcut
- Hero + card grid home page (first post with image becomes hero)
- Post archive with list-group layout, bylines, date, reading time, and tag badges
- Single post page with hero image, breadcrumb, byline with avatars, PortableText content, sticky sidebar, auto-built TOC, and "Continue reading" section
- Category and tag archives
- Server-side full-text search page
- CMS pages renderer (`/pages/[slug]`)
- Comments and comment form (threaded)
- Sidebar and footer widget areas
- RSS feed at `/rss.xml`
- Custom 404 page
- SEO meta tags with Open Graph image on post pages
- Reading time estimate from PortableText content
- Demo seed with 6 Bootstrap-themed posts, About page, categories, tags, primary menu, and widget areas
